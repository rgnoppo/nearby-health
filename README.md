 # Clinic Compass

You are a senior full-stack engineer specializing in mobile-first web applications and Supabase integration. Implement a mobile-first clinic directory application featuring an intuitive public user interface and a secure admin dashboard. The public interface must display clinics with their locations, working hours, contact info, and a unique landmark, optimized for simple mobile navigation. Public users must be able to leave ratings from one to five stars with text comments without needing an account, and submit clinic suggestions where basic info is mandatory and other details are optional. The admin dashboard must be restricted to a single admin user authenticated directly via Supabase, with no public registration allowed. The admin must be able to add, edit, and delete clinics, reorder the clinic list using up and down arrows, and manage user suggestions by approving, editing and approving, or rejecting them. Ensure the UI is clean, accessible, and fully responsive on mobile devices.
